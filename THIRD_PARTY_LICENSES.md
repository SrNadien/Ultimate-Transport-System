## Cable geometry â GPLv3 upstream

The cable shape follows [Pretty Pipez](https://www.curseforge.com/minecraft/texture-packs/pretty-pipez)
by **pyrox645**, released under the GPLv3. It is no longer shipped as a model
file: `UTBlockStateProvider` holds it as a table of boxes and faces and
generates the models from it. Every texture drawn on that shape is original
work from `tools/GenTextures.java`; no Pretty Pipez image file is included.

The side-configuration panel follows the layout of Mekanism's
`GuiSideConfiguration` under the same licence. No Mekanism image file is
included; every texture the panel draws is generated by `tools/GenGui.java`.

The battery bank levels itself the way Ender IO's capacitor banks do: blocks of
the same rung that touch each other pool their room and even out their charge on
a timer. The behaviour was studied from Ender IO's `CapacitorBankBlockEntity`;
no Ender IO code or asset is included.

## Cable models

The cable geometry is Pretty Pipez's, unchanged. It is no longer shipped as a
model file: `UTBlockStateProvider` holds it as a table of boxes and faces and
generates `block/cable_core_shape.json`, `block/cable_arm_shape.json` and
`item/cable_shape.json` from it, which the six cable variants then parent onto.

Every texture those models use is original work, generated from scratch by
`tools/GenTextures.java`. No Pretty Pipez image file is included any more.

## Assets

Every tube and station texture, blockstate and model under
`assets/ultimatetransport/textures/block/tube*`, `.../station*`,
`assets/ultimatetransport/blockstates/{tube,station,station_horizontal}.json`,
`assets/ultimatetransport/models/block/{tube,station}.json` and
`assets/ultimatetransport/models/item/{tube*,station}.json`, plus the recipes and
loot tables under `data/ultimatetransport/recipe/tube*`, `.../station.json` and
`data/ultimatetransport/loot_table/blocks/{tube,station}.json`, are copied from
Tube Transport System with only the namespace changed from `tts` to
`ultimatetransport`.
